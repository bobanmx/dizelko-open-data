# DIZELKO — OSM fuel-station location database

© OpenStreetMap contributors. Source: https://www.openstreetmap.org/copyright

This database is made available under the Open Database License (ODbL) 1.0: https://opendatacommons.org/licenses/odbl/1-0/ . Retain the attribution and license notice when redistributing. Source extracts: Geofabrik (see metadata.json for source directories, hashes and declared dates). The importer selects fuel-tagged nodes and supported simple closed ways, derives representative locations for ways, and records extract memberships. Coverage, station activity, country identity, prices and fuel availability are not verified. No price or user data is included in the registry schema. See metadata.json for provenance and counts. Snapshot date labels are not evidence that every location is up to date.
